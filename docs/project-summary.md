# JOSUI 專案摘要

> 對象：產品、設計、行銷、管理層等非技術成員  
> 一句話：JOSUI 是一個讓你在網頁上即時調整 UI 配色、預覽效果、一鍵複製設定的免費工具。

---

## 這是什麼？

**JOSUI** 是一個免費的線上工具（https://josui.space/），專門幫使用 **shadcn/ui** 和 **Tailwind CSS** 的開發者與設計師，快速調整網站或 App 的配色主題。

想像一下：你在裝潢房子時，想要試試看「牆壁刷成藍色會不會好看」——JOSUI 就是 UI 界的「試色牆」。你選一個顏色，整個頁面上的按鈕、卡片、圖表、表單會**立刻**變成那個配色，不需要等工程師改程式、重新部署。

---

## 解決什麼問題？

### 以前的痛點

1. 設計師給了一組配色，工程師要手動改十幾個 CSS 變數
2. 改完要重新編譯、刷新頁面才能看到效果
3. 不確定改了 `--primary` 之後，按鈕、卡片、圖表是否都協調
4. 要分別處理淺色模式和深色模式

### JOSUI 的做法

1. 打開網站，直接看到所有 UI 元件的配色效果
2. 點幾下就能換主題色，**即時**看到變化
3. 滿意後一鍵複製設定，貼回自己的專案就能用
4. 可以隨時切換淺色/深色模式確認

**省下的時間：** 原本調一組主題可能需要 30 分鐘到數小時，用 JOSUI 大約 2–5 分鐘。

| 使用者 | 怎麼用 |

## 目前有哪些功能？

### 已上線

- **8 組預設主題**：一鍵切換不同風格（紅、藍、綠、紫等）
- **自訂配色**：逐項調整每個顏色 token（主色、背景色、邊框色等）
- **圓角調整**：改變 UI 元件的圓角大小
- **淺色 / 深色模式**：確認兩種模式下的視覺效果
- **元件預覽區**：展示按鈕、卡片、圖表、日曆、表單等 15 種以上 UI 元件
- **一鍵複製**：匯出 Tailwind CSS 設定，直接貼入專案
- **響應式設計**：手機、平板、桌機都能正常使用

### 尚未完成

| 功能 | 說明 |
|------|------|
| 多語系 | 目前介面為英文，中文支援待開發 |
| 帳號系統 | 無法儲存或分享自己調的主題 |
| 更多導航頁面 | Pricing、更多設計等頁面規劃中 |

---

## 使用流程（3 步驟）

```
1. 打開網站 → 選一個預設主題或自己調色
2. 看看下方元件展示區的效果，切換淺色/深色確認
3. 滿意了 → 點 Copy → 複製 CSS → 貼入自己的專案
```

## 常見問題

**Q：需要付費嗎？**  
A：目前完全免費。

**Q：需要安裝什麼嗎？**  
A：不需要，打開瀏覽器就能用。

**Q：調好的主題會保存嗎？**  
A：目前刷新頁面會重置（淺色/深色偏好會保留）。未來會加入儲存功能。

**Q：支援哪些 UI 框架？**  
A：專為 shadcn/ui + Tailwind CSS 設計，匯出的 CSS 可直接用於此技術棧的專案。

**Q：可以商用嗎？**  
A：工具本身免費使用，匯出的主題設定可用於任何專案。
